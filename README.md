# SAXS-PhaseTransition 📈🔬

A Python-based toolkit designed to process, simulate, and track time-resolved Small-Angle X-ray Scattering (SAXS) data during lipid nanoparticle structural transformations[cite: 1].

## Background & Purpose
Monitoring nanocarrier phase transitions requires tracking peak shifts and inter-lamellar spacing changes over time. This open-source toolkit bridges raw scattering profiles with quantitative structural parameters using Python[cite: 1].
